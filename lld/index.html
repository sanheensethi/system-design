Book I — Low Level Design

Master object-oriented design from first principles. Every pattern you'll learn exists as a fix to a specific pain. We feel the pain first, then reach for the solution.

Table of Contents

Design Patterns Primer
Creational, Structural, Behavioral. 12 patterns with when-to-use, code, and real-world examples from Java/Python libraries.
Chapter 3
Basic Problems (Progressive)

Chapter 8
Real Company Code
Real LLD patterns from Netflix Hystrix, Guava cache, Spring framework, Java concurrent package.

How to Read This Book

If you're new to LLD, read in order. Each chapter builds on the previous. If you're prepping for interviews, jump to Chapter 3 for problems, and use Chapters 1-2 as reference.

Interview Strategy
In a 45-min LLD interview, you'll solve ONE problem. Spend 5 min clarifying, 10 min on class design, 20 min on code, 10 min discussing tradeoffs and extensions. Chapter 3's problems are all real FAANG asks.
