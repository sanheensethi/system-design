BFS vs DFS — Graph Traversal Visualization

Same graph, two strategies. BFS uses a queue and fans out level-by-level (shortest path in unweighted graphs). DFS uses a stack (or recursion) and goes deep along one branch before backtracking. Pick a start node, pick an algorithm, hit Play, and watch the difference.

BFS vs DFS — At a Glance

PropertyBFSDFS
Data structureQueue (FIFO)Stack (LIFO) or recursion
Visits nodesLevel by level (broad)Deep first, then backtrack
Shortest path (unweighted)YES — first time you reach a node is via fewest edgesNO — may reach a node via a long detour
Typical use caseShortest path, level-order traversal, finding all nodes within k hopsCycle detection, topological sort, connected components, maze solving
Space complexityO(width) — the widest levelO(depth) — the deepest branch
Time complexityO(V + E)O(V + E)
Implementation pitfallForgetting to mark as visited when enqueuing → duplicates in queueRecursion stack overflow on deep graphs → use iterative stack

Python — Both Algorithms

from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()          # FIFO
        order.append(node)
        for nbr in graph[node]:
            if nbr not in visited:
                visited.add(nbr)        # mark on enqueue, not on dequeue
                queue.append(nbr)
    return order

def dfs(graph, start, visited=None, order=None):
    if visited is None:
        visited, order = set(), []
    visited.add(start)
    order.append(start)
    for nbr in graph[start]:
        if nbr not in visited:
            dfs(graph, nbr, visited, order)
    return order

# Iterative DFS (no recursion limit):
def dfs_iter(graph, start):
    visited = set()
    stack = [start]
    order = []
    while stack:
        node = stack.pop()              # LIFO
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        # Push neighbors in reverse so first one is popped first
        for nbr in reversed(graph[node]):
            if nbr not in visited:
                stack.append(nbr)
    return order

When to Pick Which

Reach for BFS when…

  • Shortest path in an unweighted graph — BFS guarantees the first time you reach a node is via the fewest edges.
  • Level-order / nearest-first — "find all friends within 2 hops", web crawler bounded by depth, social feed expansion.
  • Small-diameter graphs — social networks where the graph is wide but shallow.
  • Finding the nearest anything — nearest exit in a maze, nearest gas station in a grid.

Reach for DFS when…

  • Cycle detection — track nodes in the current recursion stack (gray/black coloring).
  • Topological sort — post-order DFS on a DAG gives you reverse topological order.
  • Connected components — DFS from each unvisited node, count starts.
  • Backtracking / search — Sudoku, N-queens, generating permutations — DFS is your exploration skeleton.
  • Maze solving when ANY path will do — DFS finds a path quickly; BFS finds the shortest.
The one-line mental model
BFS is a ripple spreading out from the start node across the pond. DFS is a thread you unspool down one corridor until it dead-ends, then you pull it back and try the next corridor.
