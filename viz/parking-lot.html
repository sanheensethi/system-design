Class Design

ParkingLot
 ├── floors: List[Floor]
 ├── tickets: Dict[plate, Ticket]
 ├── pricing_strategy: PricingStrategy   ← swappable (Strategy pattern)
 └── park(vehicle) / exit(plate)

Floor
 ├── floor_id: int
 └── spots: List[Spot]

Spot
 ├── spot_id: str          (e.g. "F2-R5")
 ├── type: SpotType        (COMPACT | REGULAR | LARGE)
 ├── lock: threading.Lock  ← per-spot, NOT global
 ├── occupied: bool
 └── vehicle: Vehicle | None

Vehicle  (abstract)
 ├── Bike    → fits COMPACT
 ├── Car     → fits REGULAR or LARGE
 └── Truck   → fits LARGE only

PricingStrategy  (abstract)
 ├── HourlyPricing     → $10 / $20 / $40 per hour by type
 ├── FlatDailyPricing  → $50 / $80 / $150 per day
 └── DynamicPricing    → surge multiplier during peak hours

The Strategy Pattern for Pricing

Swap pricing rules without touching the ParkingLot class. Ops can A/B test flat vs. hourly vs. surge pricing by injecting a different strategy at startup.

class PricingStrategy(ABC):
    @abstractmethod
    def compute(self, spot_type: SpotType, duration_s: int) -> float: ...

class HourlyPricing(PricingStrategy):
    RATES = {COMPACT: 10, REGULAR: 20, LARGE: 40}
    def compute(self, spot_type, duration_s):
        hours = max(1, math.ceil(duration_s / 3600))
        return hours * self.RATES[spot_type]

# Injection — one-line swap
lot = ParkingLot(pricing=HourlyPricing())
# lot = ParkingLot(pricing=DynamicPricing())

The park() Method — With Proper Locking

def park(self, vehicle: Vehicle) -> Ticket:
    required = vehicle.required_spot_type()
    for floor in self.floors:                       # nearest-first: floor 1, then 2...
        for spot in floor.spots:
            if spot.type != required and not _compatible(spot.type, required):
                continue
            # Fast check (dirty read) — skip obvious no-go spots without locking
            if spot.occupied:
                continue
            # Contended check — acquire the spot's OWN lock
            with spot.lock:
                if spot.occupied:          # double-check AFTER acquiring
                    continue               # someone beat us to it → keep searching
                spot.occupied = True
                spot.vehicle  = vehicle
                ticket = Ticket(
                    plate=vehicle.plate,
                    spot_id=spot.spot_id,
                    entry_time=time.time(),
                )
                self.tickets[vehicle.plate] = ticket
                return ticket              # lock auto-released on exit
    raise LotFullError(f"No {required.name} spot available")

Edge Cases

  • Vehicle type mismatch: Truck into COMPACT → skipped during iteration; only LARGE spots considered.
  • All spots full: raise LotFullError; API returns HTTP 409. Don't silently block.
  • Malformed plate: validate regex at entry gate (^[A-Z]{2}-\d{2}-\d{4}$); reject with 400 before hitting park().
  • Simultaneous exit: exit grabs the same per-spot lock, sets occupied=False. A parallel park() that was mid-iteration simply re-reads the spot on its next lap.
  • Ticket lost: license-plate lookup fallback; operator manual-override flow with audit log.
  • Clock skew on pricing: always bill using server time, not client-provided timestamps.
