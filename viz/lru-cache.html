LRU Cache — Live Code Walkthrough

A capacity-3 LRU Cache handles these operations: put(1,'A') → put(2,'B') → put(3,'C') → get(1) → put(4,'D'). Watch the HashMap and Doubly-Linked List evolve. Notice how get(1) moves key 1 to the head, and how the put of key 4 evicts key 2 (the LRU).

Legend
Green border = head (most recently used). Red border = tail (least recently used, next to evict). Highlighted (blue) slot = currently being accessed. Faded slot = being evicted.
