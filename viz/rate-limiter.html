Rate Limiter — Token Bucket

A bucket holds up to 5 tokens. It refills at 1 token/second. Each request consumes 1 token. If bucket is empty → request denied (429). Click buttons or fire bursts to see the algorithm in action.

How it works

class TokenBucket:
    def __init__(self, capacity=5, refill_rate=1.0):  # tokens/sec
        self.capacity = capacity
        self.tokens = capacity  # start full
        self.refill_rate = refill_rate
        self.last_refill = time.now()

    def allow(self):
        # Refill based on elapsed time
        now = time.now()
        elapsed = now - self.last_refill
        self.tokens = min(self.capacity, self.tokens + elapsed * self.refill_rate)
        self.last_refill = now

        # Consume
        if self.tokens >= 1:
            self.tokens -= 1
            return True   # 200 OK
        return False      # 429 Too Many Requests
