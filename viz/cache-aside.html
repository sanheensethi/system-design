The 4 Cache Patterns

PatternHowTradeoff
Cache-Aside (this demo)App reads cache first; on miss reads DB, then writes cache.Simple. First request slow. Stale on DB writes.
Read-ThroughApp always reads cache; cache reads DB on miss itself.Same pattern, abstracted into cache layer.
Write-ThroughApp writes to cache; cache synchronously writes DB.Strong consistency. Slower writes.
Write-BehindApp writes cache; cache async writes DB (queued).Fastest writes. Risk of data loss on cache failure.
